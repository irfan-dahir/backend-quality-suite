NEGATIVE CONTROL for this case.

`nothing-lands-in-design-system` is satisfied by any run that did nothing at
all, including one that failed to resolve the fixture or refused the prompt
outright. Pairing it with proof that Step 0 ran means the decline is a judgement
the command reached after looking, rather than the silence of a run that never
started. The `records-the-decision` grader carries the same load from the other
direction: it demands a positive, specific action as the form the refusal takes.
